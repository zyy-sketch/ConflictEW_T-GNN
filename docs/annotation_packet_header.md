# κ 标注阅读包 — 评分手册与任务说明

> 本文件是标注包的固定说明；其后为 50 条推理链正文（顺序已打乱）。
> 配套：标注表（`annotation_sheet_A.csv` 或 `_B.csv`）、汇总脚本
> `scripts/summarize_kappa.py`、协议全文 `docs/protocol_kappa.md`。

## 核心目标与预期成果

- **目标**：对 50 条推理链的三个质量维度做独立 pass/fail 判断。
- **成果**：一份填完的标注表（50 行 × 3 列）。
- **用途**：与另一位标注者的判断计算 Cohen's κ（每维度 ≥0.7 为部署门槛）。

## 约束条件（请严格遵守）

1. **独立**：完成全部 50 条之前，不与另一位标注者讨论任何一条链。
2. **盲法**：本包不含金标签（该年是否真的发生了冲突）。请不要推断或查找——
   你的判断价值恰恰在于独立。
3. **二元判定**：每维度只能填 `pass` 或 `fail`，无中间档。
4. **第一直觉**：单链判读约 1.5–2 分钟；拿不准时按第一直觉，不要反复修改。
5. **时间预算**：全程约 60–100 分钟，建议分 2–3 次完成（疲劳降低一致性）。
## 三个维度的判定标准

### ① factual_accuracy（事实准确性）

**问题**：链中的数值与陈述，是否与"源数据行"一致？是否捏造了数据中不存在的信息？

- **pass**：所有因子数值与源数据行一致（允许末位四舍五入差异）；描述性陈述可由源数据行支持。
- **fail**：任一数值与源数据行矛盾；或陈述了源数据行中不存在的事实（例如引用了一个源行里没有的因子）。

### ② logical_coherence（逻辑连贯性）

**问题**：从因子证据到"风险等级 / 概率"结论的推理是否自洽？

- **pass**：结论方向与主要因子的贡献方向一致；推理链条无跳跃。
- **fail**：主要因子为强正贡献，结论却是低风险（或反之）；或推理出现"由 A 跳到无关的 B"。
- **注意**：本维度不判断"结论是否符合事实"（那是金标签的事），只判断**推理本身是否自洽**。

### ③ actionability（可操作性）

**问题**：决策者读完这条输出，能否得到可用的信息？

- **pass**：指明了风险来源与关注方向；即使是低风险链，"当前无异常信号，维持常规监测"也算可用信息。
- **fail**：只有一个概率数字而无任何解释；或建议空泛到无法行动（如"继续关注局势发展"）。

## 判定速查卡（常见组合）

| 你看到的情况 | factual | logical | actionable |
|---|---|---|---|
| 数值与源行一致，推理自洽，给出了监测方向 | pass | pass | pass |
| 数值正确，但结论方向与主要因子相反 | pass | fail | 由具体内容定 |
| 出现源行中不存在的事实 | fail | 由修改后推理定 | 由具体内容定 |
| 只有概率数字，没有任何解释 | 由源行定 | 由源行定 | fail |

## 示例（演示打分方式，非标注对象）

**示例 A（pass / pass / pass）**
链：经济压力因子贡献 +0.9（源行：gdp_growth = -1.8，失业 5.2）→ 风险等级中；
结论："经济压力偏高，建议关注财政与就业数据更新"。
打分：数值与源行一致 → factual pass；"压力偏高→建议关注"推理成立 → logical pass；
给出了关注方向 → actionable pass。

**示例 B（logical fail）**
链：主要因子贡献 -2.3（强负向）且无正向因子 → 结论"风险较高"。
打分：数值无误则 factual pass；但负向主导却得出"风险较高" → **logical fail**；
actionability 视其是否给出可执行关注点而定。

**示例 C（actionability fail）**
链：仅"概率 0.031"一个数字，无任何因子解释。
打分：actionability **fail**（数字无解释则不可用）；其余维度按源行核对。

## 源数据行字段说明

| 字段 | 含义 | 单位/范围 |
|---|---|---|
| mil_expense_log | 军费支出（现价美元）的自然对数 | 约 18–26 |
| gdp_growth | GDP 年增长率 | % |
| inflation | 通货膨胀率（年） | % |
| unemployment | 失业率 | % |
| polity_score | Polity 政体得分 | -10 至 +10 |

缺失值不显示在源数据行中；链若引用了源行中缺失的指标，按 factual fail 处理。
